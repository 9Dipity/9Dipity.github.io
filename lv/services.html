    Ārpus auditiem — praktiskas konsultācijas

    Lielākiem projektiem strādāju ar stundu vai projekta bāzes līgumiem.

    SQL Server veiktspējas optimizācija

    Diagnosticēju un novēršu datu bāzu vājās vietas, kuras citi neatrod. Tas ietver izpildes plānu analīzi, indeksu pārprojektēšanu, glabāto procedūru refaktorēšanu un vaicājumu pārrakstīšanu sarežģītām atskaišu darba slodzēm.

    • Visaptveroša izpildes plānu analīze
    • Indeksu stratēģijas izstrāde un konsolidācija
    • Glabāto procedūru refaktorēšana veiktspējai
    • Datu bāzes shēmas optimizācija augsta apjoma sistēmām
    • Veiktspējas monitoringa uzstādīšana

    C#/.NET aizmugursistēmu izstrāde

    Modernas .NET aizmugursistēmas, veidotas veiktspējai un uzturēšanas vienkāršībai. Specializējos datu apstrādes cauruļvados, regulatīvajā automatizācijā un mantoto sistēmu modernizācijā.

    • RESTful API izstrāde ar ASP.NET Core
    • Datu apstrādes cauruļvadi pakešu un reāllaika darba slodzēm
    • Dapper un Entity Framework datu piekļuves slāņi
    • Mantoto .NET Framework migrācija uz moderno .NET
    • Vienību testēšana, CI/CD cauruļvadu uzstādīšana

    Regulatīvo atskaišu automatizācija

    Esmu izveidojis SFTR, SEC un MiFID II atskaišu sistēmas, kas apstrādā tūkstošiem darījumu dienā ar nulli atbilstības pārkāpumu. Automatizēju to, ko jūsu komanda patlaban dara manuāli.

    • SFTR atskaišu automatizācija un optimizācija
    • SEC / FINRA vērtspapīru aizdevumu atskaišu ģenerēšana
    • MiFID II darījumu atskaitīšana
    • Datu validācijas ietvari un saskaņošana
    • Revīzijas izsekošanas un atbilstības dokumentācija
