    Database Design & Architecture

    I design SQL Server databases that are built right from day one — properly normalised, indexed for your real query patterns, and documented so your team can maintain them without me. I've designed schemas for systems handling 10,000+ daily transactions under regulatory scrutiny, where a bad design isn't just slow — it's a compliance risk.

    • Schema design with proper normalisation (3NF/BCNF, with practical denormalisation where needed)
    • ER diagrams, data dictionaries, and full technical documentation
    • Index strategy designed around your actual query patterns
    • Security model: roles, permissions, row-level security
    • Migration scripts from existing data sources (Excel, Access, CSV, other databases)
    • Backup, maintenance, and disaster recovery planning
